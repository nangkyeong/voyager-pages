Voyager.

Voyager는 음악 플레이리스트 제작 작업을 돕는 개인용 도구예요. 사용하는 사람이 자기 맥에 직접 설치해서 쓰고, 자기 Google 계정의 시트·Drive·YouTube 채널만 다뤄요. 공개 서비스가 아니고, 회원 가입이나 판매도 없어요.

Voyager is a personal tool for producing music playlists. Each user installs it on their own Mac and it only works with that user's own Google Sheets, Drive and YouTube channel. It is not a public service.
